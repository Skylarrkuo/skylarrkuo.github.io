在小米平板 6S Pro 上跑 Pop!_OS 26.04 与 COSMIC

Pop!_OS 26.04 LTS for Sheng · 首次公开发布

小米平板 6S Pro 12.4 的 Pop!_OS 移植现已发布。首发提供可刷入的镜像、签名本地 APT 仓库，以及本地和 GitHub Actions 两种构建方式。

  • 机型为小米平板 6S Pro 12.4，代号 sheng。
  • 系统基于 System76 官方 ARM64 镜像，桌面使用 COSMIC Wayland。
  • 实机内核为 7.2.6-sm8550-poposheng2。
  • 双系统布局为 Android A 槽、Pop!_OS B 槽，根文件系统放在独立的 linux 分区。

首发包含的适配

  • 打包了 Sheng 专用内核、设备树和硬件适配组件。内屏运行在 3048 × 2032，触控可用，Turnip 已识别 Adreno 740。
  • 修复 COSMIC「关于」页的硬件信息，补上平板型号、骁龙 8 Gen 2、Adreno 740、UFS 与系统分区容量、内屏分辨率和电池设计容量。
  • 接入省电、平衡、性能三档。默认平衡档，性能档允许 Cortex-X3 核心最高到 3.187 GHz，实际频率随负载和温控变化。
  • 真机已检查 Wi-Fi、蓝牙键鼠、内置扬声器和充电状态。日志中也记录到了 MiPPS 认证成功。

后续待发

中文拼音和自动旋转目前只部署在这台平板上。相关配置待推送到公开仓库、纳入后续镜像构建后发布。

自动旋转已实测从横屏切换到前摄在右的竖屏，画面和触摸坐标一起调整。下图是本机调试效果。左键点击顶栏图标可一键切换，右键打开菜单，勾号显示当前模式。

仓库地址

  • Skylarrkuo/popos-sheng
  • 本地构建 · GitHub Actions 构建入口

已知情况与待测

  • 初次刷入后遇到过一次重启黑屏，重新写入 linux 分区后启动成功。当时的日志不足以确定原因。
  • 摄像头已枚举，实际取景与画质待测。Pogo 键盘、指纹录入、持续快充功率和长时间负载下的温控还有待验证。 实机验证记录

刷入前

  • 先确认设备代号为 sheng，Bootloader 已解锁，Android A 槽仍能启动，且已建好至少 20 GiB 的独立 linux 分区。
  • 初次分区可能清空 Android 数据，先备份并准备恢复固件。刷机使用 Fastboot，具体分区和命令见仓库。 完整安装说明

下载

本次首发的构建编号是 Build 3.1。下载启动镜像和两卷根镜像，按 README 合并、解压并用 SHA-256 校验，再开始刷入。签名本地 APT 仓库也在附件里。 Build 3.1 下载页 · 全部 Releases
